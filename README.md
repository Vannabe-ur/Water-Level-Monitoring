## IoT-Water Level Monitoring System

A real-time water level monitoring system that measures and visualizes water levels in a tank using an ESP8266 microcontroller, a water level sensor, and an OLED display. The system sends data to a MySQL/MariaDB database and displays it on a web dashboard, allowing users to monitor the water level remotely.

### Key Features:

Real-time water level measurement in centimeters.
Status indication: SAFE, CAUTION, or FULL.
OLED display for local monitoring.
Web-based dashboard with smooth animated water visualization.
Historical data logging in a database for tracking trends.

### Use Cases:

- Home water tank monitoring.
- Industrial fluid level tracking.
- Smart irrigation or water management systems.
